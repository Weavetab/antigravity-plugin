# Weavetab MCP Plugin SDK & Runtime

Weavetab MCP plugins extend the local runtime with typed MCP tools (`defineTool`), CLI commands (`defineCommand`), prompts (`definePrompt`), resources (`defineResource`), and interceptors via `@weavetab/sdk@latest`.

Read the matching reference guide:

- **Discover, install, and invoke Weavetab plugins**: Read [references/plugin-runtime.md](references/plugin-runtime.md) (`weavetab://plugins`, `weavetab plugin use`).
- **Author hooks, interceptors, and tool overrides with `@weavetab/sdk`**: Read [references/hooks-and-overrides.md](references/hooks-and-overrides.md).

Registry & SDK docs: `https://weavetab.dev/discover` and `https://weavetab.dev/mcp/sdk`.
